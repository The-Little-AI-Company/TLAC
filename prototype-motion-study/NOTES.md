# Prototype decision

Status: option 3 selected as the primary direction. Option 1 remains a companion study.

## Question

Can a new TLAC design system carry motion through a full landing page without losing clarity, Hoolio, or human judgment?

## Selected direction

Jeff chose option 3 as the lead and also kept option 1. The lead version now uses navy ink, warm paper, electric blue, amber, and coral. It removes the green-on-green cast from the source mock.

The type system now uses Archivo for display text, Manrope for body text, and IBM Plex Mono for labels. Headings reveal by word. Large statements move with scroll position. Section content enters as the reader reaches it.

## Current verdict

The motion language works beyond the hero when it stays tied to reading order. The Fal dither field now covers the full hero behind the ship and copy. Hoolio remains a separate image asset. The selected palette and type system still need review before production work starts.

# Project Badge And Embeds

Issue #21 adds reusable exact SVG project badges and public usage guidance for
child projects.

Result: child projects can use a full or compact badge with a normal
crawler-readable attribution link back to TLAC. The guidance keeps the badge as
label attribution only and avoids ownership-transfer or repo-move language.
